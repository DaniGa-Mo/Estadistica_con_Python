# 📊 README — Término de Curso de Estadística

¡Felicitaciones por completar el curso! 🎉 Este documento resume los principales contenidos, aprendizajes y herramientas vistas durante el entrenamiento.

---

## 🎯 Objetivo del curso

Brindar una base sólida en estadística inferencial y probabilidad para el análisis de datos, la toma de decisiones y la interpretación de resultados en contextos reales.

---

## 📚 Contenidos cubiertos

### 🎲 Distribuciones de Probabilidad

* **Distribución Binomial**

  * Cálculo de probabilidades
  * Media y desviación estándar
* **Distribución de Poisson**

  * Identificación en contextos reales
  * Comparación con la binomial
* **Distribución Normal (Gaussiana)**

  * Propiedades de la distribución
  * Estandarización (Z-score)
  * Construcción y uso de la tabla Z
  * Cálculo de probabilidades asociadas

---

### 🧪 Técnicas de Muestreo

* Diferencia entre **población** y **muestra**
* Cuándo usar muestra vs. censo
* Principales métodos:

  * Muestreo aleatorio simple
  * Muestreo estratificado
  * Muestreo por conglomerados

---

### 📐 Estimación e Inferencia Estadística

* **Teorema Central del Límite (TCL)**

  * Interpretación y aplicación
* Niveles de confianza
* Niveles de significancia
* Error inferencial
* **Intervalos de confianza para la media**

---

### 📏 Tamaño de Muestra

* Cálculo para:

  * Poblaciones finitas
  * Poblaciones infinitas
* Margen de error
* Relación entre:

  * Tamaño de muestra
  * Error muestral
  * Nivel de confianza

---

## 🧠 Principales Aprendizajes

* Identificar qué distribución usar según el problema 📊
* Aplicar correctamente técnicas de muestreo 🔍
* Interpretar resultados estadísticos con confianza 📈
* Calcular intervalos de confianza y tamaños de muestra de forma práctica 🧮
